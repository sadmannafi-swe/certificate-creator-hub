# Certificate Creator Hub

build a website to generate certificates, named GenCertificates. the idea of this website is, someone wants to organized a course or seminar or related this. he will come this website and choose templete of certicates and edit the certificate, then he can submit some name by 1, 2, 3, and more then the website will generate the selected certifacate fo all name and present him. he could download all certificate in google drive.
